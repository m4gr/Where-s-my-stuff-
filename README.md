# WHERE'S MY STUFF?
#### Video Demo: https://youtu.be/8n8oZwVykHM
#### Description:

**Where's My Stuff?** is a Python-based command-line utility designed to help users track and locate their personal belongings. It serves as an intuitive personal item logger aimed at assisting individuals who frequently misplace items or experience memory-related challenges such as Alzheimer's disease.

### Features
1. **Add Items & Locations:** Enables users to quickly record any personal item alongside its precise location (e.g., "Glasses" in the "Nightstand drawer").
2. **Case-Insensitive Search:** Allows users to query the location of stored items without worrying about exact capitalization.
3. **Formatted Overview:** Displays an alphabetically sorted, clean ASCII table/list of all currently tracked items.
4. **Data Persistence:** Automatically reads from and writes to a local `items.csv` file, ensuring no data is lost when the application is closed.

### Project Structure
- `project.py`: Contains the primary execution logic within `main()` as well as independent helper functions (`add_item`, `search_item`, `format_items`, `load_items`, and `save_items`) to facilitate modularity and unit testing.
- `test_project.py`: Contains automated unit tests powered by `pytest` to verify that item additions, edge cases (such as whitespace inputs), case-insensitive searches, and string formatting execute cleanly.
- `items.csv`: The comma-separated values database automatically generated by the program to persist user records across sessions.
- `requirements.txt`: Specifies external packages used for the project setup.

### Design Decisions
A key decision was ensuring that core data manipulation functions remain fully decoupled from input/output terminal side-effects. By returning formatted strings and raising explicit `ValueError` exceptions within `add_item()`, the system maintains strict testability using `pytest` without requiring interactive mocks. Furthermore, input sanitization via string stripping ensures that invalid inputs—such as pure whitespace—are reliably caught.
